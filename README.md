# PaxCurses

PaxCurses is a curses library! PaxCurses *might* be an `ncurses` drop-in replacement.

PaxCurses uses `ncurses` API so everyone can get familiar with it

Extra features are:
Win32 support, DOS support, and POSIX (Linux, FreeBSD, etc.). Native wide character support; it uses `scroll_y` but you can still use pads for your code.
